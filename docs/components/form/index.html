@ho-dev/forms·Form

Form

pre-releasev0.2.0

Wraps fields in a native form and hands submission to the caller.

SourceStorybook

Description

When to use. Use it when a group of fields is submitted together and the page owns validation: sign-in, filters, checkout. Pair it with Field for per-field errors and a button for submission.

When not to use. Do not wrap a single toggle or a search input that submits on change; that is a plain control with its own handler. Do not expect Form to validate: it sets noValidate, prevents the default submit, and calls your handler.

Installation

@ho-dev/forms v0.2.0 · pre-release

Accessibility

Keyboard
Renders a native form element, so Enter submits when a submit button exists and fields keep their own keyboard behaviour.
ARIA
Has no role of its own. Labels, descriptions, and errors belong to Field, which injects aria-describedby and aria-invalid into the control.
Focus
Does not move focus. After a failed submit, focus the first invalid field; Field does that automatically when an error appears.
