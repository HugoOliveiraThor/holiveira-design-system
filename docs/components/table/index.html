@ho-dev/primitives·Table

Table

pre-releasev0.2.0

Displays rows of comparable data with native table semantics.

SourceStorybook

Description

When to use. Use it when the same fields repeat across rows and readers compare them: orders, members, invoices. Keep the columns few and the row height calm; the wrapper scrolls horizontally when the table is wider than the page.

When not to use. Do not use it for layout, for a single record, or for a list whose items have different shapes. For a short label-value pair, a description list is the honest structure.

Installation

Accessibility

Keyboard
Rows are static: the table itself has no custom keyboard behaviour, and a scrollable wrapper is reachable only through the browser. If a row carries an action, put a real button or link inside a cell.
ARIA
Renders a native table. The scroll wrapper receives the props you pass, so give the table a caption or an aria-label on the table element itself; a header cell gets scope="col" by default.
Focus
Only interactive content inside cells receives focus. Keep one interactive element per row when you can, so tabbing does not become a maze.
