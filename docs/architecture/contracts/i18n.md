# Package Contract: @ho-dev/i18n

Level: 1 Category: Foundation

## Purpose

Provide locale-aware formatting utilities using native `Intl` APIs. Pure functions only — no global
state, no providers, no singleton configuration.

## Responsibilities

- Locale-aware date formatting (`formatDate`)
- Locale-aware currency formatting (`formatCurrency`)
- Locale-aware relative/human-readable timestamps (`formatMessageTime`)

## Excluded Responsibilities (Deferred)

The following are explicitly out of scope for v0.x and deferred until a real requirement emerges:

- Translation function (`t()`)
- `TranslationProvider` and `useTranslation`
- Locale detection and switching
- Namespace loading and translation resources
- Pluralization rules

## Allowed Dependencies

- `@ho-dev/types` (L0) — shared types

## Forbidden Dependencies

- Any i18n library (i18next, react-intl, next-intl, etc.)
- `dayjs` or any date/time library
- `react` or `react-dom`
- Any UI or service package

## Public API

### Types

```ts
type Locale = string;
type DateInput = Date | string | number;
```

### Functions

All functions accept an options object as the second parameter (not positional parameters). This
keeps the API extensible without future breaking changes.

#### `formatDate(date, options?)`

Locale-aware date formatting using `Intl.DateTimeFormat`.

```ts
function formatDate(date: DateInput, options?: FormatDateOptions): string;
```

`FormatDateOptions` extends `Intl.DateTimeFormatOptions` and adds `locale`:

| Option   | Type   | Default   | Description                      |
| -------- | ------ | --------- | -------------------------------- |
| `locale` | string | `"en-US"` | BCP 47 locale tag                |
| (rest)   | —      | —         | Any `Intl.DateTimeFormatOptions` |

#### `formatCurrency(value, options?)`

Locale-aware currency formatting using `Intl.NumberFormat`.

```ts
function formatCurrency(value: number, options?: FormatCurrencyOptions): string;
```

| Option     | Type   | Default   | Description            |
| ---------- | ------ | --------- | ---------------------- |
| `locale`   | string | `"en-US"` | BCP 47 locale tag      |
| `currency` | string | `"USD"`   | ISO 4217 currency code |

#### `formatMessageTime(timestamp, options?)`

Human-readable relative timestamp. Returns different formats based on elapsed time:

- Same minute → "just now"
- Same hour → "Xm" (minutes ago)
- Same day → time like "4:39 PM"
- Same week → weekday name
- Same year → "Mon DD"
- Older → "Mon DD, YYYY"

```ts
function formatMessageTime(timestamp: DateInput, options?: FormatMessageTimeOptions): string;
```

| Option   | Type             | Default      | Description                              |
| -------- | ---------------- | ------------ | ---------------------------------------- |
| `locale` | string           | `"en-US"`    | BCP 47 locale tag                        |
| `now`    | `Date \| number` | `Date.now()` | Reference point for relative calculation |

## Internal API

| Export           | Description                                                    |
| ---------------- | -------------------------------------------------------------- |
| `_defaultLocale` | Default locale string (`"en-US"`) — constant, not configurable |
| `_isDateLike`    | Type guard: returns `true` for valid Date-like inputs          |
