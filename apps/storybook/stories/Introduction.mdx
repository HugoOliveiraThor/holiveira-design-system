# HO Design System

HO Design System is an engineering-first design system for building consistent, accessible web applications. This Storybook is the official component documentation and development platform.

## Package Overview

| Package              | Purpose                                                                |
| -------------------- | ---------------------------------------------------------------------- |
| `@ho-dev/primitives` | Base UI components — Button, Alert, Dropdown, Select, Table, and more  |
| `@ho-dev/ui`         | Composed UI elements — Breadcrumb, Card, ShowcaseSection               |
| `@ho-dev/forms`      | Form components — Form, Field, DatePicker, MultiSelect, and validation |
| `@ho-dev/layouts`    | Layout components — Header, Sidebar, and SidebarProvider               |
| `@ho-dev/charts`     | Chart components — Area, Bar, Line, Pie (powered by ApexCharts)        |
| `@ho-dev/icons`      | Icon library — SVG icon set with gallery view                          |
| `@ho-dev/hooks`      | Utility hooks — useClickOutside, useIsMobile                           |
| `@ho-dev/theme`      | Theme system — ThemeProvider, CSS tokens, dark mode                    |
| `@ho-dev/tokens`     | Design tokens — colors, typography, spacing, breakpoints               |
| `@ho-dev/utils`      | Utilities — cn(), cva(), helpers                                       |

## Sidebar Navigation

The sidebar is organized by package. Expand a package to see its components:

- **Primitives** — Button, Alert, Skeleton, Checkbox, Radio, Switch, InputGroup, TextArea, Select, Table, Dropdown
- **UI** — Breadcrumb, Card, ShowcaseSection
- **Forms** — Form, Field, DatePicker, MultiSelect
- **Layouts** — Header, Sidebar
- **Charts** — Area, Bar, Line, Pie
- **Icons** — Icon Gallery
- **Hooks** — useClickOutside, useIsMobile
- **Tokens** — Design token explorer

Use the **Docs** tab to see component API documentation, prop tables, and usage examples. Use the **Canvas** tab to interact with components and toggle variants via Controls.

## Theme

Toggle light and dark mode using the theme button in the toolbar. The design system uses Tailwind CSS v4 with custom color tokens configured in `@ho-dev/theme`.

## Accessibility

Every component story includes an accessibility check via `@storybook/addon-a11y`. Open the Accessibility panel to review violations and passes.
