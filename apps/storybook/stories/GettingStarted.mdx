# Getting Started

Install the packages you need from the HO Design System.

## Installation

Each `@ho-dev/*` package is published independently. Install only what your application needs:

```bash
# Primitives (base components)
pnpm add @ho-dev/primitives

# Theme (required by all packages)
pnpm add @ho-dev/theme

# UI components
pnpm add @ho-dev/ui

# Forms
pnpm add @ho-dev/forms

# Layout components
pnpm add @ho-dev/layouts

# Charts
pnpm add @ho-dev/charts

# Icons
pnpm add @ho-dev/icons

# Hooks
pnpm add @ho-dev/hooks

# Utilities
pnpm add @ho-dev/utils
```

## Quick Start

Wrap your application with `ThemeProvider` to enable the design system's theme context, dark mode, and CSS tokens:

```tsx
import { ThemeProvider } from '@ho-dev/theme';

function App({ children }: { children: React.ReactNode }) {
  return <ThemeProvider>{children}</ThemeProvider>;
}
```

Import the theme CSS for Tailwind v4 tokens and base styles:

```tsx
import '@ho-dev/theme/theme.css';
```

Now you can use any HO Design System component:

```tsx
import { Button } from '@ho-dev/primitives';
import { cn } from '@ho-dev/utils';

export function SubmitForm() {
  return (
    <div className={cn('flex gap-4')}>
      <Button variant="primary">Save Changes</Button>
      <Button variant="outline">Cancel</Button>
    </div>
  );
}
```

## Prerequisites

- **React** 19+
- **Tailwind CSS** v4
- **Next.js** 15+ (optional — HO Design System works with any React framework)
