# Getting Started

HO Design System is a set of independently versioned packages under the `@ho-dev/*` namespace. Until
the first release, the packages are consumed from this repository and demonstrated by the
playground.

## Live

- **Storybook** — [component documentation](https://hugooliveirathor.github.io/holiveira-design-system/)
- **Playground** — [full product screens](https://hugooliveirathor.github.io/holiveira-design-system/playground/)
- **Repository** — [HugoOliveiraThor/holiveira-design-system](https://github.com/HugoOliveiraThor/holiveira-design-system)
- **Issues** — [report a bug](https://github.com/HugoOliveiraThor/holiveira-design-system/issues)

## Run from the repository

```bash
git clone https://github.com/HugoOliveiraThor/holiveira-design-system.git
cd holiveira-design-system
pnpm install
cp .env.example .env
pnpm run db:generate
pnpm run dev
```

Open [localhost:3000](http://localhost:3000) for the playground and
[localhost:6006](http://localhost:6006) for Storybook.

## Install from npm (after the first release)

Each `@ho-dev/*` package is published independently. Install only what your application needs:

```bash
# Primitives (base components)
pnpm add @ho-dev/primitives

# Theme (provider, CSS tokens, dark mode)
pnpm add @ho-dev/theme

# UI components
pnpm add @ho-dev/ui

# Forms
pnpm add @ho-dev/forms

# Layout components
pnpm add @ho-dev/layouts

# Charts
pnpm add @ho-dev/charts

# Icons
pnpm add @ho-dev/icons

# Hooks
pnpm add @ho-dev/hooks

# Utilities
pnpm add @ho-dev/utils
```

## Quick Start

Wrap your application with `ThemeProvider` to enable the design system's theme context, dark mode,
and CSS tokens:

```tsx
import { ThemeProvider } from '@ho-dev/theme';

function App({ children }: { children: React.ReactNode }) {
  return <ThemeProvider>{children}</ThemeProvider>;
}
```

Import the theme CSS for Tailwind v4 tokens and base styles:

```tsx
import '@ho-dev/theme/theme.css';
```

Now you can use any HO Design System component:

```tsx
import { Button } from '@ho-dev/primitives';
import { cn } from '@ho-dev/utils';

export function SubmitForm() {
  return (
    <div className={cn('flex gap-4')}>
      <Button variant="primary">Save Changes</Button>
      <Button variant="outline">Cancel</Button>
    </div>
  );
}
```

## Prerequisites

- **React** 19+
- **Tailwind CSS** v4
- **Next.js** 16 (optional — HO Design System works with any React framework; the playground is
  built on Next.js 16)
