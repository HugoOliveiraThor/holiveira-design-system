## CSS Custom Properties

The theme system maps design tokens to Tailwind CSS classes. Toggle dark mode via the `dark` class on the `<html>` element:

```html
<html class="dark">
  <!-- dark mode styles apply -->
</html>
```

Use the `ThemeProvider` component from `@holiveira/theme` to manage theme state and persistence.

```tsx
import { ThemeProvider } from '@holiveira/theme';

function App({ children }) {
  return <ThemeProvider>{children}</ThemeProvider>;
}
```
